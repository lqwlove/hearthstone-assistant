# 燃烧 / 打脸法师

> 数据参考：HSReplay 打脸法 #594。另有魔网/私藏/法力风暴等支系——用户点名那些时勿硬套本思想。卡表是范例。改套见 `deck-edit`。

## 组牌思想

1. **法术密度**：以法术循环堆直伤，少带重随从。
2. **斩杀线清晰**：寒冰箭/火球/弹幕类必须够，缺了就搜直伤法术补。
3. **不是奥秘法/控制法**：护体与解场点到为止。
4. **角色槽位**：启动过牌 · 循环引擎 · 2–4 费直伤 · 点缀后期。

## 补位指引

- 缺斩杀 → wiki 找火球/奥术/伤害，费用 2–4；勿堆 6+ 随从。
- 手牌干 → 搜发现、抽牌、1 费循环。
- 对快攻可略增护体，仍保持法术密度。
- 参考表不够时按角色继续搜，凑满 30。
