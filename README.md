# Hearthstone Assistant

炉石传说卡牌助手——帮助玩家更快查卡、组套与分析构筑。

## 项目目标

做一个面向炉石传说玩家的实用工具，覆盖卡牌检索、套牌管理，以及后续可能的构筑建议与对局相关能力。

## 计划功能

- **卡牌检索**：按名称、费用、职业、稀有度、关键词等快速筛选
- **卡牌详情**：展示属性、效果文本、系列信息与相关说明
- **套牌管理**：创建、编辑、保存与分享套牌
- **构筑辅助**（规划中）：根据卡池与约束给出候选卡或套牌思路
- **数据更新**（规划中）：同步最新扩展包与平衡性调整
