# 中速流派框架

## 组牌思想

1. **曲线完整**：2–3 费站场与解场 → 4–5 费节奏 → 少量 6+ 终局。
2. **交易优先于纯打脸**：要能处理对方场面，再推进血线。
3. **过牌保底**：避免连续空过；缺了就搜发现/抽牌。
4. **忌过重**：第二、第三张高费威胁通常不如补中费。

## 曲线目标（约）

| 费阶 | 目标 |
|------|------|
| 1–2 | 6–10 |
| 3–4 | 8–12 |
| 5 | 4–6 |
| 6+ | 2–4 |

## 补位指引

无固定签名表。澄清职业与对抗偏好后：

1. 按 wiki-query 在 `/card_wiki/wiki/` 按费用段与角色 grep/读卡页。
2. 每档选服务「站场 / 解场 / 过牌 / 终局」角色的牌。
3. 用 `apply_deck_patch` 组到合法 30 张，再用 `curve-check` 核对。

改套流程见 `deck-edit`。
