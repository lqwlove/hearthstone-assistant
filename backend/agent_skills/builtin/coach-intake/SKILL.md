# 教练澄清（coach-intake）

按下列顺序澄清，一次只问 1～2 个问题：

1. 模式与职业是否已定（标准/狂野）
2. 目标节奏：快攻 / 中速 / 控制 / combo（或具体流派名）
3. 必带卡与禁卡
4. 对抗环境偏好（对快攻/对控制）

信息够用后：`read_file` 匹配的 archetype skill（取其思想与曲线），再按 `deck-edit` 自主组到合法 30 张。不要等待按钮，不要因参考卡表用尽而停手。
