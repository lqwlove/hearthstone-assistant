# 快攻猎人（绊索猎 / Face Hunter）

> 数据参考：HSReplay signature core（绊索猎 #870，as_of 2026-07-31；近缘 T7猎 #355）。`快攻猎` 旧名签名已过期（2024），当前以绊索线为准。改套流程见 `deck-edit`。

## 流派目标

- **每回合打伤害**：1 费启动 + 直伤 + 绊索爆发，不追求长期运营。
- 绊索线（奥术绊索 / 野兽绊索）是当前版本差异点。

## 曲线目标

| 费阶 | 目标张数（约） |
|------|----------------|
| 1 | 8–12 |
| 2 | 4–8 |
| 3–4 | 6–10 |
| 5+ | ≤4 |

开场理想：有 1 费，避免起手全是 3+。

## 换牌原则

1. **太慢**：砍 5+ 与纯过牌随从，补 1 费与直伤。
2. **缺爆发**：补绊索 + 射击类。
3. **对控制**：可带更多追踪/过牌；对快攻：优先站场与 1 费。
4. 传说游侠通常 **1 张即可**，勿重复占用曲线。
