# 萨满：兆示 / 法术线（含俗称兹伊萨）

> 数据参考：HSReplay（patch 36.2）。**当前没有「穆格·兹伊」签名原型**（dbf 126416 未出现在任何 standard signature core）。近缘是：
> - **兆示萨 #857**：终局威胁（奥拉基尔 / 灭世死亡之翼 / 末世特使）
> - **法术萨 #876**：法术爆发节奏
> - **快攻萨 #27** / **随从萨 #878**：另支，勿混用
>
> 改套流程见 `deck-edit`。

若用户坚持「双兹伊」，可把 `穆格·兹伊` 当可选支点，但先按 HSReplay 主流签名组。

## 流派目标

- **兆示线**：中速发育 → 落地高费威胁（奥拉基尔 / 灭世 / 末世特使）。
- **法术线**：廉价法术循环 + 风暴怒火类爆发，不是纯过载快攻。

## 曲线目标

| 费阶 | 目标张数（约） |
|------|----------------|
| 1–2 | 6–10（存活与过牌） |
| 3–5 | 8–12（衔接） |
| 6–10 | 2–5 终局（兆示线） |

避免「只有终局没有 1–3 费」。

## 换牌原则

1. 先确认用户要 **兆示终局** 还是 **法术爆发**（或快攻萨）。
2. **过重**：砍第二张灭世/重复 8+，补 2–4 费衔接。
3. **对快攻**：增早期解场，可砍一张慢速终局。
