# 燃烧 / 打脸法师（打脸法）

> 数据参考：HSReplay signature core（打脸法 #594，as_of 2026-07-31）。同环境还有魔网法 #866、私藏法 #872、法力风暴法 #593——用户若点名那些流派，勿硬套本 skill。改套流程见 `deck-edit`。

## 流派目标

- 用法术循环堆直伤，用寒冰箭/火球/活体烈焰清血。
- **不是**奥秘法，也不是纯控制法；少带重随从。

## 换牌原则

1. **缺斩杀**：补火球 / 弹幕 / 斩杀点，而不是再加 6+ 随从。
2. **手牌干**：补图书管理员、先知、1 费循环。
3. **对快攻**：略增护体，但仍保持法术密度。
4. 若用户要「魔网/私藏/法力风暴」，先澄清并说明本 skill 不覆盖。
