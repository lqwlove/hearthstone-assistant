# 萨满：兆示 / 法术线

> HSReplay：兆示萨 #857、法术萨 #876；无「穆格·兹伊」签名核心。卡表是范例。改套见 `deck-edit`。

## 组牌思想（先定支线）

### 兆示终局

1. 中速发育 → 落地高费威胁（奥拉基尔 / 灭世 / 特使类）。
2. 必须有 1–3 费存活与解场，忌「只有终局」。
3. 终局 2–5 张即可，重复 8+ 要砍。

### 法术爆发

1. 廉价法术循环 + 风暴怒火类爆发，不是纯过载快攻。
2. 过牌与 1–2 费法术要厚；终局靠法术而非巨型随从。
