# 虚空恶魔猎手（Void DH）

> 数据参考：HSReplay 虚空瞎 #867（patch 36.2）。下列卡牌是**范例**，不是封闭卡池。改套见 `deck-edit`；缺位用 `search_cards`。

## 组牌思想（优先遵守）

1. **成长引擎**：廉价手段把「虚空灵魂类」威胁做大；引擎断了就搜同角色牌补。
2. **快中速节奏**：前两回合要有出牌或启动，忌空过与过重 5+。
3. **武器/贴脸压血**：保留斩杀与武器线；少堆慢速嘲讽。
4. **角色槽位**：启动(1) · 引擎成长(2) · 站场(3–4) · 资源/过牌 · 点缀终局。

## 补位指引

- 缺引擎 → `search_cards`：虚空 / 邪能 / 成长类关键词，费用 1–3。
- 曲线过重 → 砍 5+，搜 1–2 费职业/中立节奏牌。
- 缺斩杀 → 搜武器或直伤，勿堆慢速。
- 表内牌已满或不合规 → 用同角色替代，继续凑满 30。
