# 虚空恶魔猎手（Void DH / 虚空瞎）

> 数据参考：HSReplay `archetypes` signature core（虚空瞎 #867，as_of 2026-07-31，patch 36.2）。胜率/梯队需 Premium analytics；本 skill 只沉淀**玩法与核心卡池**。改套流程见 `deck-edit`。

## 流派目标

- 用廉价邪能/虚空引擎把 `虚空灵魂` 做大，中期用武器与站场压血。
- 节奏偏 **快中速**：前两回合要出牌或启动，不空过。

## 换牌原则

1. **缺引擎**：优先补 虚空灵魂 / 虚空冲击。
2. **曲线过重**：砍 5+ 与重复传说，补 1–2 费（迷时战刃、海洋咒符）。
3. **缺斩杀**：保留星尘之镰；不要堆太多慢速嘲讽。
