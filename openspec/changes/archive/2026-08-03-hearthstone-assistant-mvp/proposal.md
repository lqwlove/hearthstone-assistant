## Why

炉石玩家需要一个面向 PC 的简中工具，集中完成查卡、组套，并通过对话式助手持续优化卡组。项目从零启动，需要先落地可运行的 MVP：官方卡牌数据、账号与卡组持久化、手动组套与规则校验，以及可插拔的 LLM 组牌助手。

## What Changes

- 新增 React + FastAPI 应用骨架，面向 PC Web 宽屏体验
- 新增简单账号体系（注册/登录）与 JWT 鉴权；卡组按用户隔离存储
- 新增通过暴雪官方 Hearthstone API 同步卡牌数据到本地库，界面与文案以简中为主
- 新增牌库浏览（官方卡图网格、系列/ID 区分重印、悬停放大预览）、检索筛选与卡牌详情
- 新增卡组管理：创建/编辑、草稿可存；「最终保存」必须通过构筑规则校验（标准/狂野）
- 新增独立三栏组牌页（左可选牌池、中组牌操作区、右 Agent 对话），无全局左侧导航
- 新增按卡组绑定的对话式组牌助手；服务端统一配置一份兼容 OpenAI/Claude 格式的 LLM Key；助手可自由交流，在需求足够清晰时可附带结构化改套指令并应用到当前草稿
- 数据层以 PostgreSQL 为主（`psycopg`），本地仍可切换 SQLite

## Capabilities

### New Capabilities
- `user-auth`: 简单注册登录与 JWT 会话，保护用户私有资源
- `card-catalog`: 官方 API 卡牌同步（含可读系列名与卡图 URL）、全量牌库卡图预览、检索筛选、重印区分与卡牌详情（简中，标准/狂野相关元数据）
- `deck-building`: 用户卡组 CRUD、草稿/最终保存、构筑规则校验，以及三栏组牌工作台行为
- `deck-assistant`: 一套牌一条对话线程；自由对话的组牌助手；可选结构化改套并应用到当前卡组

### Modified Capabilities
- （无——仓库尚无主规格）

## Impact

- 从空仓库引入前端（React）、后端（FastAPI）、数据库与配置项（暴雪 API 凭证、统一 LLM 配置、JWT 密钥）
- 新增对外 REST API：认证、卡牌、卡组、对话/助手
- 依赖暴雪 Hearthstone API 可用性与配额；依赖所选 LLM 提供方的兼容接口
- 第一版不做：我的收藏/合成之尘、对局追踪、卡组社区分享、每用户自备 LLM Key、移动端适配
